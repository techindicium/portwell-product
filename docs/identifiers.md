# Identifiers, PDLC track

Identifier schemes are shared across the four tracks so artifacts can be linked without
cross-track merges. Use them exactly. Inventing a local scheme is the most common reason a
cross-track reference stops resolving.

## Rule

Own the entities your track produces. Reference, never renumber, the entities another track
produces. A reference to an entity that does not exist is a finding recorded against the
referring artifact.
