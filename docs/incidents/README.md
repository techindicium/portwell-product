# Incidents and the paper trail

What actually happened, as it was written down at the time.

These are records. They are cited and traced, not edited. Correcting the system that produced an
incident is the work. Editing the write-up afterwards removes the only evidence of what the
system did.

## Reading the tracker

Work in flight is tracked in a spreadsheet. The columns mean what whoever typed them thought
they meant. `status` is free text and has several spellings of the same state. Dates are missing
on some rows. The `notes` column is where decisions went when there was nowhere else to put
them, which makes it the most useful column and the least structured.
