# Policies reaching the PDLC track

inconsistent, and not directly testable. That is the point. Module 3 asks each group to take
one and make it an executable control.

The canonical wording is in the course canon. Nothing here should be tidied, because held-out
cases depend on the inconsistencies.

## How to read the status column

| Status | Means |
| :- | :- |
| `current` | In force |
| `draft` | Written, not agreed, and therefore not a gate |
| `superseded by X` | Still reachable in the fixtures, which is a hazard rather than an error |

A `superseded` policy that is still cited by an artifact is a stale-context finding. Do not
delete the superseded version; record the finding.
